# Graph Algorithm Visualizer

Minimal React, Vite, and Tailwind CSS setup using JavaScript.

## Development

Use Node.js 22.12+ (Node.js 24 recommended) and npm.

```sh
npm install
npm run dev
```

## Production

```sh
npm run build
npm run preview
```

The production output is written to `dist/`. Tailwind is configured through
the `@tailwindcss/vite` plugin and imported in `src/index.css`.
